## Notes Design

| Élément | Choix UI | Raison |
|---------|----------|--------|
| Flèche origine → résidence (🇨🇲 → 🇫🇷) | Visuel immédiat | Montre le "parcours" du mentor, inspire confiance et identification |
| Compteur "14 mentorés" | Affiché comme stat | Preuve sociale = gage de sérieux |
| Timer 72h visible | "Expire dans X jours" | Crée une urgence douce et informe sur le process |
| Message "gratuit" | Mention explicite | Lève une barrière psychologique fréquente |
| Domaine en dropdown (parmi ceux du mentor) | Choix limité | Évite des demandes hors-champ qui frustrent les mentors |
| CTA "Devenir mentor" dans le dashboard mentee | Cross-selling doux | Le meilleur moment pour proposer = après avoir bénéficié du mentoring |
