## Notes Design

| Élément | Choix UI | Raison |
|---------|----------|--------|
| Grande image en haut du détail | Full-width cover | Les événements vivent par leur visuel |
| Badges type + prix | Couleur claire | Info clé visible en 1 seconde |
| Mini-map intégrée | Google Maps embed | Évite de quitter l'app pour se repérer |
| Avatars empilés participants | Stack +N | Donne envie socialement de rejoindre |
| Radio buttons pour le type | Pas de dropdown | 3 options max = radio, plus rapide à saisir |
| Bouton "Intéressé" en plus de "Je participe" | Engagement soft | Réduit la friction, capte les indécis |
